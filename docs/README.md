# OctoAcme Project Management Docs

This folder contains the core project management guidance used by OctoAcme. Together, these documents help teams move from an idea to a shipped outcome with clear ownership, aligned communication, and measurable delivery.

## Project lifecycle at a glance

OctoAcme follows a simple lifecycle that keeps work scoped, visible, and measurable:

1. Initiation — validate the problem, confirm stakeholders, and define success criteria.
2. Planning — turn the initiative into a backlog, timeline, and clear responsibilities.
3. Execution & Tracking — deliver iteratively, monitor progress, and escalate blockers.
4. Release & Deployment — validate quality, ship changes safely, and communicate updates.
5. Retrospective & Continuous Improvement — capture lessons learned and improve the process.

## How to use these docs

- Start with the [project management overview](./octoacme-project-management-overview.md) for a quick summary.
- Use the initiation and planning guides when starting or prioritizing a new initiative.
- Reference the execution and risk docs during active delivery.
- Use the release and retrospective guides to close the loop after shipping work.

## Key principles for OctoAcme work

- Customer-first thinking
- Iterative delivery of small, testable increments
- Clear ownership and accountability
- Regular stakeholder communication
- Evidence-based decisions and continuous learning

This repository serves as a shared source of process knowledge so teams can follow a consistent, repeatable path from concept to delivery.
